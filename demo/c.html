Method

How a lesson works

Each of the 401 steps follows the same five-part protocol. You do not scrub through a video; you operate the model.

  1. 01

    GOAL

    One precise claim the lesson will make you able to defend.

  2. 02

    SEE

    The algorithm runs in front of you, implemented from scratch in JavaScript.

  3. 03

    PLAY

    You move the sliders. The model retrains live and the numbers respond.

  4. 04

    GATE

    A question you must answer correctly before the next step unlocks.

  5. 05

    RECAP

    The claim restated — now with the evidence you generated yourself.

Verification

The lesson text is under test

“A number does not appear in a lesson unless a test recomputes it.”

Before any lesson ships, a script extracts every numeric claim from its text — accuracies, error rates, counts, probabilities — and recomputes each one from the same code the reader runs. A single disagreement blocks release.
