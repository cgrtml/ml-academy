The method

Every lesson follows the same five steps

The topic changes, the shape does not. Once you have done one lesson you know exactly what to expect from the next 122.

01 · GOAL

What you will learn

The step opens by naming what you gain, in one sentence.

02 · SEE

Watch it run

The algorithm runs in front of you. The active code line is highlighted.

03 · PLAY

Break it yourself

The sliders are yours. Push the model until it fails.

Either drive the simulation to a target, or answer correctly.
