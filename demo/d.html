Method

Every lesson is the same five-step loop

You are never shown a result you didn’t produce. 401 steps across 123 lessons, and each one ends with you predicting what the model will do next.

  1. 01
    GOAL

    One falsifiable claim, stated up front. “Gradient descent will beat your best hand-fit line.” The lesson exists to make you test it.

  2. 02
    SEE

    A live visualization draws the idea before any formula appears. Compute attention by hand before you ever see the matrix form.

  3. 03
    PLAY

    You drive. Push polynomial degree to 9 and watch training error hit 0.0000 while test error jumps to 2.11. Overfitting, felt.

  4. 04
    GATE

    The next step stays locked until you answer correctly. 154 gates, 129 questions — guessing doesn’t scale.

  5. 05
    RECAP

    What you just proved, restated with the numbers you produced — not the author’s.

Verification

The text is under test

Educational material rots quietly: an implementation gets fixed, a dataset changes, and the prose keeps quoting numbers that are no longer true. ML Academy treats lesson text like code.

“A number does not appear in a lesson unless a test recomputes it.”

Before anything ships, a test script re-runs every experiment quoted in the text. If a lesson says test error jumps to 2.11, a script just measured 2.11. Currently that is 2,395 numeric claims recomputed, with 0 disagreements — and 387 academic references behind the ideas themselves.
